# 合同评审工作台

零依赖静态页面，用于多版本合同条款评审。直接用浏览器打开 `index.html` 即可运行。

## 使用

- 打开 `index.html`，页面会在浏览器 `localStorage` 中保存评审进度。
- 点击“重置演示”恢复内置样例数据。
- 点击“导出修改对照”下载 Markdown 报告。

## 覆盖的评审规则

- 按合同版本归档每条意见，老版本未处理意见不会串入新版本。
- 同一条款下并排展示多人改法，可采纳一种、合并多种或全部驳回并写理由。
- 新版本到达后，老意见保持挂起，并显示仍未表态人员。
- 未回复人员可催办或先跳过，催办和跳过原因都会留痕。
- 同一人前后意见实质冲突时，由评审组选择以前次或后次为准。
- 完全冲突的条款可冻结，依赖该条款的下游条款自动标为阻塞。
- 顶部指标和“继续未决”用于定位卡在哪一条、哪个人。
- 定稿后再追加意见，会把条款重新打开，旧结论保留为历史。
- 定稿前检查未决冲突、裁定、缺人、未覆盖意见；导出报告单列未处理项。

## 文件

- `index.html`：页面结构。
- `styles.css`：视觉样式。
- `app.js`：演示数据、状态推导、交互和导出逻辑。
